# فلسطين حرة | Free Palestine

موقع ثنائي اللغة (العربية والإنجليزية) عن القضية الفلسطينية والحضارة الفلسطينية والمقاطعة الاقتصادية، مع قائمة مصادر.

A bilingual (Arabic/English) website about the Palestinian cause, Palestinian civilization, and economic boycott, with a list of sources.

## الملفات | Files

- `index.html`: الموقع كاملاً في ملف واحد (HTML + CSS + JS) | the whole site in one file
- `assets/`: الشعار (SVG وPNG) | logo files (SVG and PNG)
- `.nojekyll`: لمنع معالجة GitHub Pages للملفات | disables Jekyll processing on GitHub Pages

## التشغيل محلياً | Run locally

افتح `index.html` في المتصفح مباشرة. | Just open `index.html` in a browser.

## النشر على GitHub Pages | Deploy

1. ارفع الملفات إلى مستودع جديد | Push these files to a new repository.
2. `Settings` ← `Pages`
3. Source: `Deploy from a branch` ثم اختر `main` و `/ (root)` | choose `main` and `/ (root)`.
4. سيظهر الموقع على | The site will appear at `https://USERNAME.github.io/REPO/`

## ملاحظات | Notes

- يستخدم خطوط Google Fonts (Reem Kufi وAmiri) ويعمل بخطوط بديلة عند عدم توفر الإنترنت | Uses Google Fonts with system fallbacks offline.
- زر اللغة يحفظ اختيارك في المتصفح | The language toggle remembers your choice in the browser.
- راجع المعلومات من مصادرها الأصلية قبل النشر، خصوصاً أرقام اللاجئين ونسب المناطق وقوائم المقاطعة | Verify facts against original sources before publishing, especially refugee figures, area percentages and boycott lists.
