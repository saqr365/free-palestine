# فلسطين حرة | Free Palestine

موقع ثنائي اللغة عن القضية الفلسطينية والحضارة الفلسطينية والمقاطعة الاقتصادية، بمصادر دولية وأكاديمية.<br>
A bilingual website on the Palestinian cause, heritage and economic boycott, built on international and academic sources.

**[saqr365.github.io/free-palestine](https://saqr365.github.io/free-palestine/)**

</div>

## المميزات | Features

- عربي (RTL) وإنجليزي (LTR) مع حفظ الاختيار | Arabic (RTL) and English (LTR), choice remembered
- وضع فاتح وداكن تلقائي ومتجاوب مع الموبايل | automatic light/dark mode, mobile-first
- ملف واحد بدون مكتبات خارجية، والخطوط فقط من Google Fonts | one file, no libraries; only Google Fonts
- أنيميشن يحترم إعداد "تقليل الحركة" | animations that respect "reduce motion"
- يمكن إضافته لشاشة الهاتف الرئيسية كتطبيق (PWA manifest + أيقونات) | installable shortcut with home-screen icons

## التشغيل | Run

افتح `index.html` في المتصفح. | Open `index.html` in a browser.

## النشر | Deploy

`Settings` ← `Pages` ← `Deploy from a branch` ← `main` / `(root)`

## الهيكل | Structure

```
index.html          الموقع | the site
site.webmanifest    بيانات الاختصار | shortcut / install manifest
assets/             الشعار والأيقونات | logo and icons
```

## ملاحظات | Notes

- راجع المعلومات من مصادرها الأصلية قبل الاعتماد عليها. | Verify facts against the original sources.
- قوائم المقاطعة الشعبية ليست كلها ضمن القائمة الرسمية لحركة BDS. | Popular boycott lists are not all on the official BDS target list.
